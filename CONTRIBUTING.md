# Contributing

**Status: initial project rules.** Follow the JavaScript only constraint in [AGENTS.md](AGENTS.md). Keep changes scoped to the current task, inspect existing component usage before changing shared UI, and update the related docs and [progress log](docs/PROGRESS.md). Do not report a command as passing unless it was run and passed. Do not introduce credentials or private customer data. The project has not yet established a PR or release workflow.
